Narrative & Setting

🌌

Cosmic Horror Cyberpunk

The player is a "Netrunner" consciousness injected into a forgotten, sentient, alien data-structure built on Redis primitives. Time loops endlessly as the cluster decays. You don't restart; the node evicts you.

🧠

Diegetic Hacking

Redis isn't a side-terminal—it's the fabric of reality. You type commands on seamless holographic overlays mid-combat to alter the physical laws of the sector you're trapped in.

⏳

Time Loop Mystery

Every time you succumb to the "OOM Reaper" (Out of Memory), the world resets, but your Redis Command Mastery persists. You slowly decode the alien architecture to execute a final cluster failover.

Combat & Mechanics Mapping

A hybrid of high-octane FPS and puzzle-solving. Your abilities are directly mapped to Redis production skills unlocked via the Skill Tree.

// Scene Setup Prototype
import { Canvas } from '@react-three/fiber'
import { Physics } from '@react-three/rapier'
import { EffectComposer, Glitch, Bloom } from '@react-three/postprocessing'

export const Mode3D = () => {
    const isCorrupted = useGameStore(s => s.worldState.isCorrupted);

    return (
        <Canvas gl={{ antialias: false, logarithmicDepthBuffer: true }}>
            <Physics gravity={[0, -20, 0]}>
                <PlayerController />
                <LevelGeometry />
                <EnemyAI />
            </Physics>

            <EffectComposer disableNormalPass>
                <Bloom luminanceThreshold={1} mipmapBlur intensity={1.5} />
                {isCorrupted && <Glitch delay={[1.5, 3.5]} duration={[0.1, 0.3]} strength={[0.2, 0.4]} />}
            </EffectComposer>
        </Canvas>
    )
}

Implementation Plan

Phase 1: Bootstrapping the Void (Engine & Entry)

Dual-Mode Architecture

Integrate a smooth entry point separating the 2D Isometric Engine from the 3D WebGPU Engine. Setup React Three Fiber Canvas with initial Rapier physics hooks and a First-Person/Third-Person camera controller.

Phase 2: The Physical Datacenter (World & Geometry)

Asset Pipeline & Post-Processing

Build procedural sci-fi corridors representing clustering shards. Implement `@react-three/postprocessing` for heavy Bloom, Chromatic Aberration, and Glitch effects. Ensure WebGL2 fallback for WebGPU targets.

Phase 3: Cybernetic Combat (Mechanics)

Shooter Core & Physics

Develop the weapon system, projectile physics, and enemy hitboxes. Integrate the existing SoundEngine.js with Three.js PositionalAudio for aggressive, terrifying sound design when enemies (rogue keys/zombie processes) attack.

Phase 4: Diegetic Redis Hacking

State & Consequence Binding

Map the existing `gameStore` and `ConsequenceEngine` to 3D entities. When a player casts "Shield" (creates a caching key), spawn a physical 3D barrier. Render floating diegetic terminals using `` from Drei for hacking puzzle rooms.
